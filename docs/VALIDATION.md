# v0.1.0 验证记录

验证日期：2026-10-28（北京时间）。本版是单机试用工具，验证对象为文件导入、来源与计算规则、人工复核流程、持久化和导出；未执行真实模型 API 调用，也未开展研究人员效率评估。

## 领域与接口

在 Windows、Node.js 24.16.0 下执行 `npm test`，20 项通过。覆盖金额精度、金额边界匹配、缺失值和异常基期、候选注入、人工核对声明、版本冲突、修改和恢复后的确认失效、来源篡改、进程重启、导出过滤、文件类型与 PDF 解析，以及浏览器/Agent 接口边界。另验证了最大合法金额在元/万元/亿元间换算，以及派生计算失败时不会覆盖原项目。

## 原始公开 PDF 与 Agent CLI

另外使用一份已下载的中际旭创 2026 年半年度报告摘要，实际导入 7 页 PDF，通过 `context` 读取第 2 页文字，再以该页原值构造候选并使用 CLI 导入。原始营业收入 41,777,861,795.03 元与 14,789,074,837.80 元，确定性计算结果为 182.49%。候选保持待复核，导出事实数为 0、待办数为 1。

这条检查验证真实 PDF 字节、页文本与 CLI 的衔接，不是模型自动抽取准确率测试。公开报告未打包进入仓库；仓库内的财务测试资料均为构造样例。

## 浏览器与分发

浏览器验收的实际结果、用例范围和复现方式见 [QA.md](QA.md)。每次运行使用新的隔离数据目录，覆盖导入、候选、人工确认、修改后失效、导出、响应式窗口以及真实进程停止/重启。

Release 的 `VALIDATION.txt` 记录最终 ZIP 在全新目录中的安装、Windows 启动脚本和浏览器复验结果；`SHA256SUMS.txt` 可校验下载文件。结果仅适用于记录中的系统与运行环境。macOS/Linux 启动脚本随包提供，尚未在对应操作系统上实机验收。

## 尚未验证或不支持

- 扫描件 OCR、Excel 工作簿、非人民币金额和跨报告口径核定。
- 对所有复杂表格、财报格式的抽取准确率；文本可追溯不能替代列对应和口径的人工判断。
- 公网多人协作、企业身份认证、可信人工签名和原生 ChatGPT MCP App。
- 外部 Agent 的模型质量、传输策略或组织数据使用许可。
